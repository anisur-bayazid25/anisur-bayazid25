## Featured research tools and projects

### [eQc — Easy Qual Coding](https://github.com/anisur-bayazid25/eQc)

A local desktop application for **qualitative data analysis (QDA)**. Import interviews, field notes, documents, and images; code text and image regions; organise codebooks; write memos; and explore themes using queries, matrices, and framework analysis.

- Local research workflow with no account or cloud upload required.
- Support for Word, PDF, text, Markdown, images, and structured CSV datasets.
- Project exchange through QDPX and JSON, with collaboration over a local network.

[Download eQc](https://github.com/anisur-bayazid25/eQc/releases/latest) · [User guide](https://github.com/anisur-bayazid25/eQc/blob/main/USER_GUIDE.md) · [Source code](https://github.com/anisur-bayazid25/eQc)

### [MapBanai — Offline Field Data Collection for Android](https://github.com/anisur-bayazid25/MapBanai)

An Android application for **mobile GIS, surveys, and geospatial data collection**. Collect survey responses, GPS tracks, points, lines, polygons, and geotagged photos in the field, including without an internet connection.

- Import XLSForm surveys with conditional logic and validation.
- Capture spatial features and export survey or GIS data to CSV and GeoJSON.
- Share project definitions between phones and use English or Bangla interfaces.

[Download MapBanai](https://github.com/anisur-bayazid25/MapBanai/releases/latest) · [Features and setup](https://github.com/anisur-bayazid25/MapBanai#readme) · [Source code](https://github.com/anisur-bayazid25/MapBanai)

### [Dhaka Heat Vulnerability Atlas](https://github.com/anisur-bayazid25/HVI)

An interactive **Heat Vulnerability Index (HVI)** atlas for Dhaka, Bangladesh. Explore grid and ward maps of heat vulnerability, exposure, sensitivity, and adaptive capacity, alongside healthcare facility locations and distance comparisons.

- Compare spatial indicators and vulnerability classes.
- Explore healthcare proximity using road-network and straight-line distances.
- Read the data sources and methodology, download selected data, and share map views.

[Explore the interactive atlas](https://anisur-bayazid25.github.io/HVI/) · [Data sources](https://github.com/anisur-bayazid25/HVI/blob/main/docs/DATA.md) · [Methodology](https://github.com/anisur-bayazid25/HVI/blob/main/docs/METHODOLOGY.md) · [Source code](https://github.com/anisur-bayazid25/HVI)
